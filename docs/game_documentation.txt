Clash of the Cities - Mission Net Zero - Comprehensive Documentation

Overview:
Clash of the Cities - Mission Net Zero is a real-time, multiplayer cooperative simulation game focused on urban waste management and the circular economy. Players assume one of three specialized roles (MRF, Broker, Municipality) and collaborate in timed game sessions to balance competing objectives: Budget ($), City Health (%), and CO₂ Emissions. The system is designed for both educational and training purposes and is implemented as a web application with a TypeScript/Node.js backend and a Next.js frontend.

Roles and Responsibilities:
- MRF (Materials Recovery Facility):
  - Collects incoming waste batches, grades materials, and prepares materials for sale.
  - Interacts with local queues, processes waste into reusable materials, and manages internal inventory.
  - Key pages: `/dashboard/mrf-collection`.

- Broker:
  - Manages auctions, places bids, and interacts with external wholesalers to buy/sell materials.
  - Responsible for optimizing revenue while supporting overall team objectives.
  - Key pages: `/dashboard/broker-inventory`.

- Municipality:
  - Oversees waste collection, city projects, and public health considerations.
  - Allocates resources to city projects, collects waste from citizens, and interfaces with MRF for transfers.
  - Key pages: `/dashboard/municipality`.

Core Game Concepts:
- Game Session: An instance of a running game identified by `sessionId`. Sessions contain the authoritative `gameState`, which is broadcast to connected clients via WebSockets.
- Game State: Central JSON object tracking players, budgets, city health, CO₂, waste batches, inventories, auctions, and turn timing.
- Queue: Waiting list of waste batches to be processed by MRF or transferred between roles.
- Waste Batch: An object representing a collected waste payload with metadata such as `id`, `mass`, `quality`, `status`.
- Inventory & Auctions: Materials produced by MRF can be listed in auctions. Brokers interact with auctions and external wholesalers to fulfill demands.
- Countdown & Turns: Real-time or simulated timing controls govern the session duration and turn transitions. Countdown events are broadcast in real-time.

Frontend Architecture (Next.js):
- `app/` contains top-level routes and nested layouts.
- `app/dashboard/` houses key gameplay pages including `mrf-collection`, `broker-inventory`, and `municipality`.
- `components/ui/` contains reusable UI elements such as `ShiftLog`, `selectedBox` widgets, and new `GameChatbot` component for in-play assistance.
- `services/` provides API wrappers to the backend endpoints (e.g., `gameService`, `mrfService`, `brokerService`, `municipalityService`).
- `stores/` (Zustand) handles auth and notification state (e.g., `authStore`, `notificationStore`).
- `hooks/` contains specialized hooks such as `useWebSocket` for realtime interactions.

Backend Architecture (Express + TypeScript):
- `src/app.ts` boots the server, registers middleware, routes, WebSocket setup, and background schedulers (system checks, pairing, countdown broadcasting).
- `routes/` map endpoints to `controllers/`. New assistant endpoints are under `routes/chatbotRoutes.ts`.
- `controllers/` are lightweight adapters that validate and forward requests to `services/`.
- `services/` contain the business logic (e.g., `gameService`, `mrfService`, `brokerService`). The new `chatbotService` handles conversational logic and retrieval.
- `utils/` contains helpers: `AppError`, `asyncHandler`, `response` helpers.
- `models/` define persisted entities (Mongoose) such as `GameSession`, `User`, `Lobby`.

Real-time Communication:
- The backend uses `socket.io` with an initialized `WebSocketService` to broadcast game state updates, countdowns, system messages, and player actions.
- Clients subscribe to various events such as `game-state-update`, `game-state-full`, `system-message`, and `player-action`.

APIs:
- Game state: `/api/games/...`
- MRF endpoints: `/api/mrf/...`
- Broker endpoints: `/api/broker/...`
- Municipality endpoints: `/api/municipality/...`
- Auth & Lobby management: `/api/auth`, `/api/lobby`
- Chatbot endpoints (new):
  - `POST /api/chatbot/message` - send user message, returns assistant reply and optionally context used.
  - `GET /api/chatbot/status` - returns vectorstore document count/status.

Chatbot & RAG Integration:
- A lightweight in-memory vectorstore scaffold (`chatbotVectorstoreService`) stores documents for retrieval.
- `chatbotService` performs retrieval (currently token-overlap heuristic) and, if `OPENAI_API_KEY` is provided, calls the LLM provider (default `openai`) to generate an answer using retrieved context.
- The recommended production flow uses a persistent vector database (Chroma, Pinecone, pgvector) with embeddings. A helper Python script is provided to build a Chroma vectorstore from the game documentation.
- The chatbot is exposed only in gameplay pages (`mrf-collection`, `broker-inventory`, `municipality`) as a floating UI widget that expands to a chat window.

Data Flow for Chatbot (Simple):
1. Frontend `GameChatbot` sends `POST /api/chatbot/message` with message + optional sessionId/pageContext/history.
2. Backend `chatbotController` validates payload and calls `chatbotService.ask()`.
3. `chatbotService` retrieves candidate context chunks from the in-memory vectorstore, then either:
   - Calls OpenAI Chat Completions (if API key set) with system prompt + retrieved context, or
   - Returns a graceful fallback answer referencing retrieved local context.
4. Controller returns standardized API response to client.

Extensibility Notes:
- To improve retrieval accuracy, replace the in-memory `chatbotVectorstoreService` with a persistent embedding-backed vector DB (Chroma, Pinecone, etc.).
- Add scripts to periodically ingest new game content, policy docs, or FAQs into the vectorstore.
- Add rate limits and per-session quotas for the chatbot endpoint to protect API costs.

Operational & Deployment Notes:
- Environment variables are validated via Zod in `src/config/env.ts`. Add `OPENAI_API_KEY`, `CHATBOT_MODEL`, and related configs there in production.
- The backend exposes health checks at `/` and `/api/health`.
- Background jobs run via `setInterval` inside `app.ts` for scheduled checks and pairing; consider migrating to a job scheduler for scaling.

Development & Local Run:
- Backend: `npm install` then `npm run dev` from `Besse-backend`.
- Frontend: `npm install` then `npm run dev` from `Besse-frontend`.
- To enable the chatbot with local docs, run the provided generator to produce `Generation/chroma_docs.json`, then restart backend which auto-loads this file into the in-memory vectorstore.

Maintenance Suggestions:
- Add automated ingestion pipelines for game rules and help docs so the vectorstore remains up-to-date.
- Periodically re-run the Chroma builder if you want an on-disk vector index for faster retrieval and more advanced RAG.

## Circular Economy Fundamentals & Sustainability Framework

### What is the Circular Economy?

The circular economy is an economic system designed to eliminate waste and continuously use resources through recovery, regeneration, and restoration. Unlike the traditional linear "take-make-dispose" model, the circular economy operates on a cyclical principle where materials are recovered and reintroduced into production cycles, dramatically reducing resource extraction and environmental impact.

The circular economy model replaces the linear economy's fundamental flaw: depletion of finite natural resources. In a circular system, products are designed for longevity, repairability, and recyclability from the outset. This principle applies directly to the waste management value chain in Clash of the Cities - Mission Net Zero, where players manage material flows through collection, sorting, processing, and reintroduction into markets or production loops.

Key circular economy tenets include:
1. **Design for Circularity**: Products engineered from inception with end-of-life recovery in mind. Materials are selected for recyclability and reusability potential.
2. **Material Loops**: Closed-loop systems where materials cycle repeatedly. Biological loops return organic matter safely to ecosystems; technical loops maintain industrial materials at high value indefinitely.
3. **Extended Producer Responsibility (EPR)**: Manufacturers bear responsibility for products throughout their lifecycle, incentivizing sustainable design.
4. **Service Over Ownership**: Business models transition from selling goods to selling services (e.g., "material as a service"), decoupling profit from material consumption.
5. **Waste as a Resource**: No true waste exists; byproducts become inputs for other processes or industries.

The game directly models these principles: MRFs recover value from waste streams, brokers facilitate material redistribution and secondary market access, and municipalities balance collection infrastructure with city development—all while minimizing CO₂ emissions inherent in the system.

### Environmental Engineering & Waste Management Systems

Waste management systems are foundational infrastructure for urban sustainability. Modern environmental engineering approaches waste holistically, integrating collection logistics, treatment technologies, contamination control, and emissions reduction.

**Collection Phase:**
Municipality players manage waste collection efficiency. Optimal collection routes minimize fuel consumption and operational CO₂. Collection frequency impacts landfill diversion—higher frequency reduces contamination and loss of recoverable materials. Trade-offs exist: more frequent collection increases vehicle emissions; infrequent collection increases contamination and landfill burden.

**Sorting and Materials Recovery:**
MRF operators employ mechanical and manual sorting to separate incoming mixed waste streams into homogeneous material categories (paper, cardboard, metals, plastics, glass). Advanced MRFs use optical scanners, magnetometers, and eddy-current separators for precision. Contamination—food waste, hazardous materials, non-recyclables mixed in—degrades material quality and downstream value, reducing broker demand and economic incentive.

High-grade materials command premium pricing. Clean aluminum, for instance, can cycle indefinitely without property degradation and is infinitely recyclable. Plastics degrade incrementally with each cycle (downcycling), necessitating careful classification by polymer type (PET, HDPE, PVC, LDPE, PP, PS, Other).

**Processing & Secondary Markets:**
Processed materials are aggregated by brokers and sold to end-markets: manufacturers seeking recycled input (reducing virgin material extraction), retailers, and wholesalers. Broker inventory management balances holding costs against market price fluctuations—selling too early leaves upside unrealized; holding too long incurs storage and opportunity costs.

**Transportation & Logistics Emissions:**
Every material transfer incurs transportation CO₂. Moving waste from collection points to MRF, then processed materials to brokers or end-markets, generates cumulative emissions. Game mechanics model this: longer supply chains or inefficient logistics increase total system emissions, pressuring players to optimize transport and reduce idle inventory.

### Carbon Footprint & Lifecycle Emissions in Waste Systems

A material's carbon footprint encompasses greenhouse gas (GHG) emissions across its entire lifecycle: raw material extraction, processing, manufacturing, transportation, use, and end-of-life (EOL) treatment. Waste management systems directly influence the EOL phase and determine whether materials re-enter production (low-carbon pathway) or are landfilled/incinerated (high-carbon alternative).

**Landfill & Incineration Emissions:**
When organic waste (food, yard debris, paper) enters landfills anaerobically, microbes produce methane (CH₄), a potent GHG with ~28–36 times the global warming potential of CO₂ over a 100-year period. A single decomposing apple or discarded cardboard box in a landfill generates methane for decades. Incineration burns waste for energy recovery but produces direct CO₂ emissions and incomplete combustion byproducts.

**Recycling Carbon Benefit:**
Recycling dramatically lowers lifecycle emissions by:
- Eliminating virgin resource extraction (mining, forestry, petroleum drilling) and its associated emissions.
- Reducing processing energy; recycled aluminum requires ~95% less energy than primary aluminum smelting.
- Avoiding landfill methane production.
- Displacing future virgin material production.

Example: One recycled aluminum can avoids ~9g CO₂e vs. primary production. Recycled steel saves ~2.5 kg CO₂e per ton vs. virgin ore processing.

**Transportation Carbon Intensity:**
Transport mode defines carbon efficiency:
- Truck: ~0.1–0.2 kg CO₂ per ton-km.
- Rail: ~0.025 kg CO₂ per ton-km (4–8x lower).
- Ship: ~0.01 kg CO₂ per ton-km (10–20x lower).

Game mechanics reflect this: inefficient local collection increases per-unit emissions; aggregating materials for rail or ship transport reduces carbon per ton transferred. Brokers that consolidate shipments and use efficient logistics reduce total system emissions and win favor with municipality partners.

**System-Level Carbon Intensity:**
The waste system's overall carbon footprint is the sum of:
1. Collection logistics emissions.
2. MRF operational energy (sorting machinery, facility lighting, HVAC).
3. Processing energy (shredding, compaction, baling).
4. Transportation between actors.
5. Avoided landfill/incineration emissions (credited as a benefit).
6. Minus recyclable material revenues offsetting operational costs.

Players optimize this integrated system. A municipality that collects efficiently reduces collection emissions. An MRF that sorts with high purity enables higher broker revenues and market demand, justifying continued operation. A broker that aggregates and batches shipments reduces per-unit transport emissions. Together, the team's mission is to maximize material recovery and minimize net system emissions while generating revenue for reinvestment and city development.

### The Municipality's Role in Circular Economy Leadership

Municipalities are the orchestrators of circular systems. They control or regulate waste collection infrastructure, set policy frameworks, and manage citizen/business incentives. In Clash of the Cities - Mission Net Zero, the Municipality player is central to system success.

**Waste Collection & Infrastructure:**
Municipalities operate or contract collection services. Decisions include:
- **Collection frequency**: Daily pickup reduces contamination and landfill overflow but increases vehicle emissions. Bi-weekly or tri-weekly pickup is standard in developed economies. Trade-off: balance citizen satisfaction and contamination control.
- **Separate collection**: Comingled (single-bin) collection simplifies logistics but increases MRF contamination and sorting cost. Separate collection (paper, organics, metals, plastics in distinct streams) improves material purity and market value but raises collection costs (multiple vehicle routes, citizen compliance).
- **Organic waste management**: Food and yard waste can be composted anaerobically (biogas production) or aerobically (compost product) rather than landfilled. This eliminates methane emissions and produces valuable soil amendments or renewable energy.
- **Hazardous waste streams**: Proper handling of batteries, e-waste, bulky items, and toxic materials prevents environmental contamination and enables specialized recycling.

**City Projects & Public Health:**
City projects funded by waste management budget represent sustainability investments:
- **Green infrastructure**: Parks, urban forests, and green roofs increase carbon sequestration, reduce urban heat island effects, and improve air quality (lowering respiratory disease).
- **Clean energy transition**: Solar/wind installations reduce grid emissions.
- **Water management**: Stormwater retention and treatment prevent pollution.
- **Education & engagement**: Campaigns promoting source separation and reduction increase citizen participation and system efficiency.

High city health (%) reflects successful municipal management: lower waste generation per capita, higher material recovery rates, cleaner air/water, and public satisfaction.

**Policy & Market Development:**
Municipalities set conditions for circular economy success:
- **EPR policies**: Producer responsibility schemes encourage manufacturers to design for recyclability.
- **Procurement standards**: Preferentially buying recycled-content or circular-design products creates stable end-market demand.
- **Landfill diversion targets**: Legal mandates (e.g., "70% diversion by 2030") force system optimization.
- **Economic instruments**: Taxes on virgin materials, subsidies for recycled products, or deposit-return schemes alter market incentives.

In the game, Municipality actions directly influence MRF demand and broker market stability. Strategic municipal policy amplifies the entire circular ecosystem.

### The MRF's Role in Material Recovery & Waste Processing

Materials Recovery Facilities are the industrial backbone of circular economies. MRFs are sorting and processing plants that convert mixed waste streams into sortable, marketable material fractions. MRF operational excellence directly determines system recovery rates and material quality.

**MRF Sorting & Grading Processes:**

Mixed waste arrives at the MRF in waste batches (bags, containers, compacted trucks). The sorting process uses a combination of manual and mechanical techniques:

1. **Manual Sorting**: Workers remove contaminants and non-recyclables by hand on a conveyor belt. This labor-intensive step is critical for quality; a single food-stained plastic bag or piece of glass can contaminate an entire batch destined for plastic reprocessors.

2. **Mechanical Separation**:
   - **Screens**: Separate material by size (e.g., remove small non-recyclables, split fiber from rigid plastics).
   - **Magnets**: Extract ferrous metals (steel cans, appliances).
   - **Eddy-current separators**: Extract non-ferrous metals (aluminum, brass, copper).
   - **Optical/Near-infrared scanners**: Identify plastic types (PET, HDPE, etc.) and enable targeted ejection or routing.
   - **Air classification**: Separate light materials (film, paper) from dense materials (metals, glass).

3. **Baling & Compaction**: Sorted materials are densified into bales (paper, cardboard, metals) for efficient transport.

4. **Quality Grading**: Materials are graded by purity (%-acceptable) and contamination level. High-grade materials attract premium broker pricing.

**MRF Economics & Operational Costs:**

MRF profitability depends on:
- **Tipping fees**: Revenue from municipalities/waste generators paying to dispose at the facility.
- **Material sales**: Revenue from selling sorted fractions to brokers and end-markets.
- **Operational costs**: Labor, utilities, equipment maintenance, equipment wear.
- **Market volatility**: Commodity prices for aluminum, steel, paper, plastic fluctuate daily on global exchanges, impacting revenue.

A well-run MRF generates sufficient material sale revenue to offset tipping fees and costs, sometimes even paying municipalities a "negative tipping fee" (subsidy). A poorly-run MRF (high contamination, low labor efficiency, equipment downtime) runs at a loss and may close, forcing waste back into landfills.

In the game, MRF players manage incoming batch quality, grading accuracy, and processing speed. High-quality output attracts broker interest and premium pricing. Low-quality output (contaminated materials) depresses broker demand and drives prices down.

**Environmental Impact of MRF Operations:**

MRF operations generate emissions:
- **Facility energy**: Sorting machinery, lighting, HVAC, and compressed air systems consume electricity (carbon-intensive if from fossil-fuel grids).
- **Labor transportation**: Worker commuting emissions (mitigated by transit access and remote work options).
- **Equipment emissions**: Diesel-powered balers and loaders.

However, MRF operations avoid far greater emissions from landfill decomposition and virgin material extraction. Net lifecycle comparison shows recycling-focused MRFs as carbon-negative investments despite operational emissions.

**MRF Role in the Circular Value Chain:**

The MRF sits at a critical juncture: it converts low-value mixed waste (negative value to generators) into medium-value sorted fractions (positive value to brokers and manufacturers). This value creation is the economic engine motivating waste diversion. Without functioning MRFs, circular systems collapse—waste defaults to landfills, and virgin resource extraction accelerates.

### The Broker's Role in Circular Market Development

Brokers are intermediaries connecting supply (MRF-processed materials) to demand (manufacturers, retailers, secondary markets, wholesalers). They manage inventory, price discovery, market development, and risk.

**Broker Functions in Circular Supply Chains:**

1. **Aggregation**: Brokers accumulate material batches from multiple MRFs into larger, homogeneous lots attractive to bulk buyers. A single MRF's 5-ton steel shipment may not justify buyer logistics; 50 tons from aggregated sources does.

2. **Quality Assurance**: Brokers inspect, test, and certify material quality, providing end-buyers confidence in specs and consistency.

3. **Market Linkage**: Brokers develop relationships with end-buyers (secondary plastic processors, steel mills, paper mills, wholesalers). They provide market intelligence on pricing, demand forecasts, and supply gaps.

4. **Risk Management**: Brokers manage price volatility through forward contracting, hedging, and strategic inventory positioning. Holding inventory carries risk—prices may fall, requiring discounted sales; or prices may rise, enabling capital gains.

5. **Logistics Coordination**: Brokers arrange transportation, typically negotiating volume discounts with carriers and optimizing routes. Efficient logistics reduce per-unit transport costs and emissions.

**Broker Economics & Market Dynamics:**

Broker profit margin = sell price – buy cost – operational costs (labor, facility, transport, insurance).

Margins vary by material and market condition:
- **Aluminum**: High-value, stable demand, narrow margins (0.5–2% per transaction) due to high competition.
- **Mixed plastics**: Volatile pricing, contamination risk, wider margins (2–5%) compensate for risk.
- **Cardboard**: Commodity-like, predictable demand, tight margins (0.5–1.5%).

Brokers succeed by:
- **Accurate price discovery**: Knowing fair market prices and negotiating optimal buy/sell prices.
- **Demand creation**: Developing end-buyer relationships and identifying niche markets (e.g., specialty recyclers for rare materials).
- **Inventory management**: Balancing holding costs against upside price movements.
- **Logistics efficiency**: Consolidating shipments, using lower-cost transport modes, and minimizing dead-leg miles.

**Broker Impact on System Circularity:**

Brokers stabilize the circular loop by:
- **Creating incentive for MRF output**: High broker demand and fair pricing motivate MRF investment and operational excellence.
- **Enabling end-market access**: Without brokers linking to distant manufacturers and processors, local MRFs have limited markets and may not survive economically.
- **Market transparency**: Competitive brokering prevents monopoly exploitation and ensures fair prices along the chain.
- **Innovation**: Brokers pioneering new end-markets (e.g., plastic-to-fuel conversion, chemical recycling) expand the scope of circular recovery.

A municipality's waste system thrives when brokers are profitable and competitive, incentivizing high-quality material demand and driving MRF performance.

**Broker Carbon Footprint Optimization:**

Brokers minimize logistics emissions by:
- **Consolidation**: Aggregating smaller shipments into full-truck-load (FTL) or container-load (CL) quantities, reducing per-unit transport emissions.
- **Mode shifting**: Routing rail or maritime shipments instead of truck-only when supply chain permits.
- **Regional sourcing**: Developing networks of local MRFs and buyers to reduce average transport distance.
- **Reverse logistics**: Arranging backhaul loads to reduce empty vehicle miles.

A strategic broker that optimizes logistics reduces total system emissions while maintaining profitability.

### Mission Alignment: CO₂ Reduction & City Development

Clash of the Cities - Mission Net Zero encodes a profound sustainability insight: environmental protection and economic prosperity are not opposed. The game operationalizes the circular economy as a path to both.

**The CO₂ Reduction Imperative:**

Global climate science unequivocally links greenhouse gas emissions to warming. The IPCC (Intergovernmental Panel on Climate Change) reports that limiting warming to 1.5–2°C requires global emissions reductions of 43–50% by 2030 and net-zero by 2050. Urban waste systems contribute 5–10% of global emissions when including collection, processing, landfill gas, and embodied material extraction. Optimizing municipal waste systems is a high-leverage climate intervention.

Waste reduction, reuse, recycling, and circular design lower emissions by:
- Avoiding virgin resource extraction (mining saves 70–95% energy vs. primary production for most materials).
- Preventing landfill methane (a 28–36x more potent GHG than CO₂ over 100 years).
- Extending product lifespans through remanufacturing and repair.
- Enabling renewable material cycling (biomass loops) and closed technical loops.

The game's CO₂ metric represents cumulative system emissions. Players collectively minimize this through:
1. Municipality: Optimize collection logistics, promote source separation, invest in organic processing.
2. MRF: Maximize material recovery rates, maintain quality, minimize facility emissions.
3. Broker: Consolidate shipments, use efficient transport, develop end-markets.

**City Development & Economic Prosperity:**

Circular economies generate economic value:
- **Job creation**: Material recovery, processing, and remanufacturing are labor-intensive, creating skilled and semi-skilled employment.
- **Revenue streams**: Tipping fees, material sales, and service contracts provide municipal revenue for reinvestment.
- **Cost avoidance**: Diverting waste from landfills and incinerators defers expensive infrastructure expansion and avoids long-term remediation costs.
- **Innovation clusters**: Regional leadership in circular technologies attracts investment, R&D centers, and startup ecosystems.
- **Supply security**: Recycled material streams reduce dependence on volatile global commodity markets.

In the game, municipal budget ($) grows through:
- MRF tipping fee revenue.
- Material sales revenue (if municipality owns MRF assets or receives profit-sharing).
- City project investments that generate return (e.g., green infrastructure increasing property values and tax base).

The game explicitly tracks **City Health (%)**, reflecting public well-being:
- Lower air pollution from reduced landfill emissions and incineration.
- Healthier water quality from reduced landfill leachate and improved stormwater management.
- Improved livability from green infrastructure and reduced waste visibility.
- Employment and economic opportunity from circular economy jobs.

**The Win Condition: Balanced Prosperity**

Clash of the Cities - Mission Net Zero succeeds when players achieve:
1. **Minimized CO₂**: System emissions held below a target threshold through efficient operations and strategic investments.
2. **Growing budget**: Economic viability—operations self-sustaining, reinvestment possible.
3. **Rising city health**: Public satisfaction, environmental quality, and livability improving.

This mirrors real-world municipal sustainability planning: cities that implement circular economy principles achieve greenhouse gas reductions while generating economic growth and improved quality of life. The game teaches that circularity is not a sacrifice but a superior business model—profit and planet are aligned.

**Scaling to Real-World Impact:**

Clash of the Cities - Mission Net Zero educates players (students, municipal staff, sustainability professionals) on system dynamics. Insights gained translate to real policy:
- Understanding trade-offs (collection frequency vs. emissions).
- Recognizing interdependencies (municipality demand drives MRF investment drives broker service).
- Appreciating carbon accounting (lifecycle perspective, avoided emissions, system boundaries).
- Valuing circular design (frontload recovery into product design).

As players master the game, they internalize circular economy logic and may champion these principles in their professional and civic roles.
